# GitHub repository description

Thermalright Mini Display is an independent, lightweight native Windows utility for displaying custom still images and animated GIFs on the integrated USB LCD of the Thermalright Burst Assassin 120 Vision (BA120 Vision) cooler. The application is focused on image presentation rather than system monitoring: it discovers the supported HID interface, validates the BA120 Vision PM52/SUB0 identity response, prepares media for the panel's 240 × 320 RGB565 display format, and transfers the frame data using the device's Type-2 HID protocol. The native C++/Win32 implementation uses Windows system APIs and GDI+ to avoid a bundled .NET runtime, while providing image scaling, 90°/270° rotation, GIF frame-rate control, an LCD preview, persistent settings, system-tray operation and optional Windows startup. Static-image playback reuses its encoded frame packets for periodic keep-alive transfers because the tested BA120 panel reverted to its factory screen after a short period without USB refresh. The project is hardware-specific, independently maintained and not an official Thermalright product; the documented protocol values and performance readings should be treated as observations from the tested setup, not guarantees for other coolers or firmware versions.
